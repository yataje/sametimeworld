# SameTimeWorld · v0.5.0

같은 시기의 세계 사건과 국가별 지도자를 비교하는 시간축입니다.

## 운영

개인 관리 패키지에서 `Manage.cmd`를 실행합니다. **검사·미리보기** 또는 **GitHub에 반영** 버튼을 사용합니다. 원본 선택, 읽기 전용 검사, 로컬 백업, 압축·암호화, 게시 파일 검사를 한 번에 수행합니다. GitHub 전송 이후 Actions가 성공해야 공개 사이트에 적용됩니다.

개인 원본과 관리 도구는 `_local/`에 보관하며 GitHub에 게시하지 않습니다. GitHub에서 받는 코드만으로는 원본을 편집할 수 없습니다. 관리용 전체 패키지는 별도로 보관하세요. Git for Windows, Node.js 22 이상, Python 3.10 이상이 필요합니다. Git 인증은 기존 Git Credential Manager를 이용하며 별도 토큰을 소스에 저장하지 않습니다.

## 공개 파일

브라우저는 같은 사이트의 불투명한 이름을 가진 패키지 하나만 읽습니다. gzip 압축과 AES-256-GCM 인증 암호화를 사용합니다. 원본 이름, 편집 이력, 로컬 경로, 백업, 인증 자료는 공개 패키지에 포함하지 않습니다. 지도·검색·지도자·확대축소 기능은 유지합니다.

**이 암호화는 노출을 줄이는 조치이지 접근 통제가 아닙니다.** 공개 웹페이지가 읽기 위한 키를 포함하므로, 분석할 줄 아는 사람은 표시 자료를 복원할 수 있습니다. 과거의 공개 커밋이나 이미 공개된 서비스 데이터까지 제거하지는 않습니다.

자료가 바뀌면 공개 데이터 버전이 자동 증가하며 파일 이름도 바뀝니다. 내용이 같으면 재암호화하지 않습니다. 손상된 패키지는 게시와 읽기가 차단됩니다.

## 개발·배포

`npm test`와 `npm run build`는 Node.js 기본 기능만으로 동작합니다. `dist/`에는 검증된 공개 파일만 생성합니다. 기본 브랜치의 GitHub Actions가 이 폴더만 Pages로 배포합니다. 개발 서버에는 Vite를 선택적으로 사용할 수 있습니다.

실제 브라우저 검사: `python tests/browser-smoke.py` (Playwright 별도 설치 필요).

역사 내용과 지도 경계의 사실성을 새로 검증한 릴리스는 아닙니다. 기존 자료의 날짜 정밀도·출처·검증상태를 보존합니다. 지도 자료 고지는 `MAP_DATA_NOTICE.txt`를 참조하세요.
