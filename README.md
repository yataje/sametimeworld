# SameTimeWorld

**The World at the Same Time** — 같은 날짜의 세계 사건을 한 화면에서 비교하는 웹 프로젝트입니다.

## 개발 환경

- Visual Studio Code
- npm
- Vite
- Firebase Realtime Database

## 실행

```powershell
npm install
npm run dev
```

또는 `Start_Dev_Server.cmd`를 실행합니다.

## 빌드

```powershell
npm run build
```

GitHub Pages용 결과물은 `dist` 폴더에 생성됩니다.

## Firebase

- project: `sametimeworld`
- Realtime Database: `asia-southeast1`
- data roots: `events`, `leaders`, `meta`
