# 로컬 저장 EXE
Windows용 오프라인 저장 도구입니다. 기본 폴더 C:\sametimeworld는 실행 화면에서 바꿀 수 있습니다.
실행 전 이 EXE는 다운로드 폴더 등 대상 프로젝트 밖에 두고 DB 편집기, 개발 서버와 업데이터를 닫습니다.
새 파일과 해시를 확인한 뒤 기존 폴더를 복사하여 사용자 파일을 보존합니다. 적용 직전에 원래 폴더 전체를 옆의 SameTimeWorld_Backups\폴더명-날짜-시각-고유번호로 이동해 백업하고 새 폴더를 적용합니다.
실패 시 기존 폴더를 유지하거나 복원합니다. 손상된 자료, 사용 중인 파일·SQLite journal/WAL, 심볼릭 링크·정션을 만나면 건너뛰고 덮어쓰지 않고 중단합니다.
백업은 자동 삭제하지 않습니다. 파일 내용 보존용 프로젝트 백업이며 Windows 전체 이미지나 VSS 백업은 아닙니다.
복원: 실행 중인 프로젝트 도구를 모두 닫고 현재 프로젝트를 다른 이름으로 보관한 뒤, 원하는 날짜의 백업 폴더를 원래 프로젝트 경로로 복사 또는 이동합니다. 원래 폴더 구조(.git 및 사용자 파일 포함)가 백업 안에 남습니다.
네트워크·레지스트리 변경·자동실행 등록·브라우저 실행은 하지 않습니다. 배포 EXE는 코드서명 인증서가 없으므로 Windows가 알 수 없는 게시자로 표시할 수 있습니다.
시리즈 UI의 '내 시리즈'는 브라우저 저장소에 있으며 프로젝트 폴더 백업에 들어가지 않습니다. 시리즈 창의 '내 시리즈 파일 저장'으로 별도 보관합니다.
