# v0.8.0 사건 상세 프레임

사용자 승인: 메타데이터 고정 / 사건 본문만 스크롤 / 등록된 시리즈·개념 선택 및 액션 고정 / Google 검색·시간축 복귀 고정. ‘목록’은 오른쪽 독립 프레임의 **사건카드**를 연다. 카드 선택 시 왼쪽 상세가 바뀐다. 모바일에서도 옆 프레임을 유지하며 각 본문은 독립적으로 스크롤한다.

선택 버튼 자체는 이동·재생·목록 열기를 수행하지 않는다. 처음·이전·자동 TTS·다음·목록 액션은 선택 후 활성화된다. 새 사건에서도 같은 선택을 유지하고 본문을 맨 위로 올린다. 다른 선택을 하면 기존 오른쪽 목록을 닫아, 새 액션을 누를 때까지 임의로 실행하지 않는다. 오른쪽 목록은 60건 단위 페이지로 모든 사건에 접근하며 현재 사건이 표시된다.

버튼은 기존 concept/series/custom membership으로만 생성한다. 제목에서 태그를 추론하지 않는다. 예시 사건 8479의 현재 등록 항목은 전쟁과 군사, 전쟁, 부산포, 조선이다. 임진왜란·일본 역사 같은 버튼을 근거 없이 추가하지 않는다. master DB, 사건/지도자 패킷, 시리즈 카탈로그, 좌표는 변경하지 않는다.

TTS는 OS/브라우저 Web Speech API를 사용한다. 한국어 음성이 제공되어야 하며, 없거나 오류가 발생하면 안내하고 자동 이동을 멈춘다. 제목·표시 날짜·장소·정리된 설명을 읽고 마지막 문장이 끝나면 다음 사건으로 이동한다. 출처 URL·원문 날짜·검토 메모는 읽지 않는다. 정지, 수동 사건 이동, 관련 항목 변경, 시간축 복귀, 페이지 숨김/종료 시 취소한다. 취소 전의 콜백은 다음 사건을 열 수 없다. 기기 음성에 따라 네트워크를 사용할 수 있으며, GPT나 유료 API 키를 호출하지 않는다.

검증: 순수 관계·재생 상태 테스트, 실제 Chromium에서 데스크톱/모바일/짧은 가로 화면의 프레임 고정·본문 스크롤·오른쪽 카드·선택-실행 분리·Esc를 확인한다. 자동재생 순서는 명시적으로 주입한 음성 시험기로 검사한다. 이는 사용자 PC의 한국어 음성이 실제로 들렸다는 증거가 아니다. 기본 데이터/지도/브라우저 테스트 및 Windows 백업 EXE 검사를 함께 수행한다.

로컬 저장은 기존 백업 선행 EXE를 사용한다. 기본 C:\sametimeworld, 전체 기존 폴더(사용자 파일·숨김 파일·.git 포함)를 인접 SameTimeWorld_Backups에 보존한다. DB와 좌표를 이번 UI 수정에서 바꾸지 않는다.
